# Welcome To My Personal Website

The code base for my personal website, made with Next.js, Tailwind CSS and Preline UI and served on Vercel.

## Stack

- Next.js 16 (App Router) and React 19
- Tailwind CSS 4 (CSS-first configuration in `app/globals.css`)
- Preline UI 5
- Formik + Yup for the contact form, Web3Forms for delivery
- react-hot-toast and react-icons

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - production build
- `npm run start` - run the production build
- `npm run lint` - lint with ESLint
